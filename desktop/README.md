# LLMs-powered Translator 桌面版 0.3.0

这是独立的桌面托盘程序，使用 GLM 查询选中的英语单词，不依赖 Zotero 插件。Windows 版已打包；macOS 版源码和构建脚本已准备，但尚未在 macOS 编译或运行验证。

## Windows 运行

解压 `llms-powered-translator-Windows-0.3.0.zip`，保留整个文件夹，运行其中的 `LLMs-powered-Translator.exe`。首次运行会打开设置；填入 GLM Coding Plan API Key，选择触发方式后保存。默认模型是 `glm-5.3-flash`，模型名称可自行修改。程序仅调用 Coding Plan 接口。密钥保存在 Windows 凭据管理器，设置文件不保存密钥。程序在系统托盘运行；右击图标可以手动查询、修改设置或退出。点击查询窗口外部、按 Esc 或在外部程序使用方向键取消选区时，弹窗会收起；关闭查询窗口不会退出托盘程序。

触发方式可选：

- 划词自动弹出：在其他支持 Windows UI Automation TextPattern 的应用中，用鼠标划选单词或双击单词。
- 快捷键：选中单词后按 `Ctrl + Alt + W`。如果快捷键冲突，请换用自动模式或手动查询。

系统只能读取应用通过辅助功能暴露的选区；对于不支持的应用，或扫描图片，自动模式可能没有结果，快捷键会显示提示，可使用托盘的手动查询。不会模拟复制，也不会修改剪贴板。未获取上下文时会在查询窗口标明。不会改变被选中的文本。

## 连接问题排查

在托盘右击图标选择“设置”，点击“测试连接”。此操作使用当前输入或已保存的 Coding Plan 密钥向智谱发送一个短测试请求（最大 32 个输出 token），可能消耗少量套餐额度；程序不会在界面或日志显示密钥。成功收到流式响应表示连接和认证请求已被接受，但还需划词验证完整输出。失败时会区分代理、证书、连接超时、响应超时、连接中断和 HTTP/业务码。用户可将错误文字告知开发者，切勿发送密钥。

网络连接默认直连，不读取系统或进程代理设置，也不使用环境变量指定的证书路径；程序仍会验证服务器证书和主机名。如直连网络仍进行 HTTPS 扫描，或系统时间有误，证书校验仍可能失败。测试时不要关闭设置窗口。Coding Plan 适用范围以智谱规定为准。

## 深色主题与升级

程序根据系统主题切换明暗配色，正文和按钮使用高对比文字，词形小标题使用较浅的灰色。旧版默认 `glm-4.7-flash` 会迁移到 `glm-5.3-flash`，自定义模型保留；旧版标准 API 选项已移除，原来的模式设置与凭据保留。如果原先保存的是标准 API 密钥，需要在设置中改填 Coding Plan 密钥。

智谱的 Coding Plan 限定官方指定工具与产品环境；本程序是独立词汇工具，是否可使用该套餐需要向智谱确认，调用可能受限制。参见 https://docs.bigmodel.cn/cn/coding-plan/usage-notes 。GLM-5.3-Flash 不能关闭思考，程序使用较低思考强度；完整首次查询时间不能保证。

## 功能与数据

查询时仅支持一个英文单词或连字符词。若辅助功能返回可信的选区边界和附近文字，会尝试从实际相邻文字补全单词，并把前后各约 220 个字符作为上下文随请求发送给智谱 GLM。各应用的辅助功能能力不同，可能无法取得上下文、补全或选区；不同论文中的同一个词按上下文分别缓存。缓存仅存进程内存，退出后清除。没有接入柯林斯词典。

选中词后发出核心请求，显示释义、词形和同词族。首次打开搭配、词根或近义词时，共用第二个 GLM 请求；切换时仅展开一项。首次查询时间取决于网络、模型和服务负载，不能保证 500 毫秒以内。请遵守智谱对应 API 或 Coding 套餐的使用规则。

## macOS 本机构建

在 Mac 上安装 Python 3.10 或更新版本，解压源码包，在终端进入源码目录并执行：

```sh
chmod +x build-macos.sh
./build-macos.sh
```

程序生成在 `dist/LLMs-powered-Translator.app`。运行前可能需要在“系统设置 → 隐私与安全性”中为该应用开启“辅助功能”和“输入监控”，具体提示取决于 macOS 版本。快捷键是 `⌘ + ⌥ + W`。系统钥匙串保存 GLM 密钥。当前源码没有开发者签名或公证，分发给其他 Mac 时需自行处理签名和公证；不同处理器架构应在目标 Mac 上分别构建。macOS 适配未实测，不能保证所有应用和选区可用。

## 测试与限制

Windows 已使用独立的合成文本测试窗口验证 UI Automation 选区、部分单词补全和上下文；深色与浅色配色、设置迁移、Coding 请求参数、禁用代理并保持证书校验、错误分类、测试连接、取消选区收起和凭据保留通过模拟检查；GLM 请求、紧凑格式、请求缓存与按需面板用模拟服务测试。不同应用的选区、实际 GLM 请求和 macOS 运行效果仍需要分别验证。应用退出后后台线程可能需要等待正在进行的网络请求结束。用户可重新启动应用；当前没有设置开机自启动。
