# LLMs-powered Translator：Zotero 插件 0.11.0

Zotero 10 阅读器选中英文单词后显示紧凑词汇卡片。词义、必要词形和同词族通过留白与分隔线区分，不显示栏目标题；词性使用 n.、v.、adj. 等缩写，同词族逐项换行，单数不显示。搭配、词根和近义词默认隐藏，通过按钮按需查询；每次仅展开选中的一项，内容逐条换行。

## 词形排版

词形使用紧凑的两行排列：灰色小字标签以不带空格的斜杠连接，例如“三单/过去/过分/现在分词”；下一行的对应英文形式使用两侧带空格的斜杠连接，例如“runs / ran / run / running”。“过分”指过去分词，不等于过去完成时；“现在分词”是用于进行时等结构的形式，不等于完整的现在进行时。如果模型确实返回完整的过去完成时或现在进行时，分别标记为“过完”和“现在进行”。支持解析已有缓存中的常见中英文标签；核心结果的词形缺少标签时会重新查询，无法确认时提示用户重新划词，不会按位置猜测词形，也不在词形区显示孤立的 n. 词性标记。模型仍可能不按要求输出。

## 原文上下文与补全

选中 PDF 中的单词或单词片段时，插件尝试从阅读器的字符位置恢复该选区所在的完整英文单词，标题用“选中片段 → 完整词”表示补全。仅使用 PDF 文字层中的实际相邻字符，不依靠模型猜测；选区或字符位置不可靠时保留原选词。当前仅处理一个英文单词或含连字符的词，无法处理跨页、分列错序、扫描图片或文本层错误等所有情况。

如果成功获取 PDF 上下文，会把目标词附近前后各最多约 220 个字符随核心请求以及按需的合并请求发送给 GLM。模型被要求优先结合原文解释，缩写有展开形式时优先参考原文；定义不在附近时可能仍无法准确判定。弹窗显示“未获取上下文”时，使用选词进行常规查询。上下文相关缓存仅存于内存，重启后清除，不写入 Zotero 偏好；不同上下文分开缓存。由于使用 Zotero 阅读器内部结构，具体 PDF 与 Zotero 版本需要实际验证。

## 近义词

点击“查看近义词”可展开与当前词义和词性相近的词，以及中文意思和简短用法区别；会优先请求适合论文的较高级表达。词族关系不等于近义关系，例如 optimal 和 suboptimal 是相关词，意思并不相同。结果由 GLM 生成，不保证一定有合适的高级近义词，也不能保证完全准确。

## 名词复数

模型会先判断当前释义下名词的可数性，只在确认常见可数用法时列复数；不确定时省略。针对所选的 `forward-compatibility`（前向兼容性），界面会阻止显示复数，并显示“通常不可数”。这是一条针对该术语的特殊保护，不会依据后缀批量判断其他名词。其他名词的判断仍来自 GLM，不能保证完全正确；插件尚未接入柯林斯数据进行校验。

## 动词与同词族

选中动词的屈折形式时，请 GLM 识别原形并解释原形；标题在识别出不同的原形时显示“选中词 → 原形”，词形区列出适用的第三人称单数、过去式、过去分词和现在分词（包括不规则变化）。同词族涵盖常见跨词性派生词和前缀衍生词；同一个词的不同词性和释义放在同一行，重复的词性和释义只保留一次，动词屈折变化不作为派生词。未能获取上下文时，部分形式可能同时是独立的名词或形容词，原形和词性由模型判断，可能存在歧义或错误。

没有取得上下文时，本版本可沿用 0.9.0 的核心和合并查询缓存；核心缓存缺少必要词形标签时会重新查询。取得上下文后会重新请求并在内存中按上下文分别缓存。升级自更早版本时，旧版核心解析以及独立的词根、搭配缓存不会用于新查询，重新生成可能产生 API 费用。

## 配置

在 Zotero 选择“编辑 → 设置 → LLMs-powered Translator”。可修改 GLM 模型和接口、保存 GLM 密钥、填写可选的柯林斯 API 密钥及授权词典代码、清除密钥或词汇缓存。现有密钥保留；输入框留空则保持已保存值不变，密钥通过 Zotero 的系统密钥存储加密保存。

为缩短等待，本版本将标准 API 下仍使用旧默认 `glm-5.3` 的配置迁移至 `glm-4.7-flash`；其他已选择的模型保持不变。GLM 4.7 系列请求关闭思考；GLM 5.3 系列使用低思考强度。模型是否可用、免费额度和费用以智谱控制台为准，必要时可在设置中换回原模型。Coding Plan 需遵守智谱规定的适用工具范围。

可自行尝试标准 API 下的 `glm-4.7-flashx`，该模型按量收费，具体可用性与价格以智谱控制台为准；插件不会自动更换型号。GLM 4.7 系列采用非思考模式和流式输出。请使用多个不同的新词比较首段和完整耗时，确认效果与质量。

设置页显示最近一次新词请求的首段正文耗时和完整请求耗时，从发起请求开始计时；只保存在内存，不保存单词或密钥，重启后重置。缓存命中与搭配、词根、近义词合并请求不计入。数据不会自动刷新，查询后重新打开设置页查看。

## 安装

选择“工具 → 插件 → 齿轮 → 从文件安装插件”，选择 `llms-powered-translator-zotero-0.11.0.xpi`，按 Zotero 提示完成安装。建议安装后重启 Zotero。旧版本保存的密钥和设置不需要重新填写。

## 时间和数据

GLM 结果采用流式显示，之前成功查询过的词汇结果从本地缓存读取；首次查询仍需等待网络与服务，无法保证完整结果在 500 毫秒内返回。首次点击“查看搭配”“查看词根”或“查看近义词”时，三个部分由一个额外的 GLM 请求一起生成；其他按钮复用同一请求和结果。点击另一按钮会收起之前的内容；再次点击当前按钮可收起。三个部分都成功返回时会缓存，缺失部分可收起后重试；旧版独立的搭配或词根缓存不会作为新版合并结果使用。无上下文的 GLM 缓存保存在 Zotero 配置中，包含单词和模型生成的结果；上下文相关缓存仅存内存。两类缓存各最多 100 项，可在设置中清除。柯林斯数据不缓存、不发送给 GLM。当前没有柯林斯授权时不会显示柯林斯配置提示。

模型生成的释义、词族、词源可能有误，专业用法和词源应以可靠词典为准。当前未实现跨页或全文检索上下文，也未实现离线柯林斯词典。

## 验证范围

本版本通过源码语法、名词复数保护、动词原形标题与词形渲染、同词多词性去重、旧缓存处理、三个可选部分互斥展开、逐条排版、PDF 选区补全、上下文缓存隔离、英文和中文词形标签斜杠分隔渲染、无标签旧缓存重新查询及请求参数的模拟检查；PDF 字符提取、实际 GLM 输出与 Zotero 界面仍需安装后验证。安装包中的本地更新地址为 Zotero 清单占位地址，更新须手动安装。
